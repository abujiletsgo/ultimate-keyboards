### Full description
```text
얼티밋 키보드(Ultimate Keyboards)는 책상 위 맥북 내장 키보드로 안드로이드 휴대폰과 태블릿(갤럭시, 갤럭시탭 등)에 바로 글자를 입력할 수 있는 무선 연동 키보드 앱이에요. 맥북에서 설정한 홈로우 모드(Home Row Mods), 레이어, 두 키 동시 입력 콤보, 두벌식 한/영 전환이 휴대폰에서도 똑같이 작동해요.

한 번 연결하고 단축키로 바로 전환해요
• 맥 화면에 뜬 QR 코드를 휴대폰으로 스캔하면 같은 Wi-Fi(또는 NetBird 사설망) 안에서 종단간 암호화(P-256 + AES-256-GCM)로 안전하게 연결돼요.
• 맥북에서 전환 단축키(기본값: 양쪽 Command 키 동시 탭)를 누르면 휴대폰 입력 모드로 바뀌고, 다시 누르거나 Esc 키를 길게 누르면 즉시 맥북 타이핑으로 돌아와요.
• 휴대폰 화면 아래에는 얇은 상태 바만 표시되며, 자리를 비울 때 버튼 한 번만 누르면 삼성 키보드나 Gboard 같은 원래 휴대폰 키보드로 바로 돌아갈 수 있어요.

맥북의 스플릿 키보드 기능과 한/영 전환 그대로
• 맥북의 리매핑 엔진을 먼저 거쳐 전달되므로, A·S·D·F / J·K·L·; 홈로우 모디파이어, 스페이스바를 누른 채 쓰는 H·J·K·L 방향키 레이어, 두 키 콤보(K+L 엔터, I+O 백스페이스, W+E Esc)를 휴대폰 카톡이나 메모에서도 그대로 쓸 수 있어요.
• 한국어 두벌식 조합과 영어 입력 전환, 단어·줄 단위 편집 단축키를 지원해요.
• 맥용 데스크톱 앱에서는 카라비너(Karabiner) JSON 파일이나 복잡한 코드 없이 클릭만으로 맥북 키 매핑을 설정할 수 있고, 코른(Corne)·릴리58 같은 무선 스플릿 키보드의 ZMK·QMK 키맵 편집과 GitHub Actions 펌웨어 빌드까지 한곳에서 처리해요.

솔직한 작동 범위와 개인정보 보호
• 글자 입력과 텍스트 편집 전용이에요. 마우스 커서 이동이나 홈 화면 전환 같은 원격 제어 기능은 제공하지 않아요.
• 휴대폰 화면이 잠겨 있거나 입력창이 열려 있지 않을 때, 또는 금융·결제 앱의 자체 보안 키패드가 뜰 때는 맥 화면에 이유를 알려 주고 키 입력을 맥에 그대로 남겨 두어 글자가 유실되지 않아요.
• 광고 없음, 회원가입 없음, 키 입력 기록 저장 없음. 모든 키 신호는 기기 간 암호화 통신으로만 전달돼요.

지원 사양 및 요금 안내 (구독 없는 일회성 결제)
```
